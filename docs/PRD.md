# 个人管理系统 PRD v1.0

## 1. 产品概述
### 1.1 愿景
> 成为产品经理的「职业操作系统」，无缝融合个人成长与项目管理，为AI增强工作流奠基。


### 1.2 目标用户
- **核心用户**：资深产品经理（技术背景，注重效率）
- **设备环境**：主力设备MacBook Pro，辅用Windows台式机
- **关键诉求**：  
  - 5秒内找到3个月前的申邦项目需求文档  
  - 将零散会议记录自动关联到能力地图  
  - 离线状态下仍可访问核心资料

## 2. 功能需求
### 2.1 全局能力
| 功能       | 详细描述                                                                 | 交互说明                  |
|------------|--------------------------------------------------------------------------|---------------------------|
| **统一搜索** | 支持跨模块检索笔记/项目/文档                                             | 顶部搜索框，支持关键词+标签过滤 |
| **数据埋点** | 自动记录：<br>- 每次访问的笔记ID<br>- 高频搜索关键词<br>- 文件打开频率    | 后台静默运行，不干扰用户  |
| **离线模式** | 最近访问的10个文档自动缓存到本地                                         | 无网络时显示缓存标识      |

### 2.2 产品经理空间
#### 2.2.1 知识库
- **核心字段**：  
  ```python
  title: str  # 笔记标题
  content: str  # Markdown内容
  tags: list[str]  # 多标签（例：["支付设计","AI"]）
  source: enum["会议","课程","竞品","灵感"]  # 资料来源
  confidence: int(1-5)  # 信息可信度
